# 📺 追番进度管理 - 使用说明

## 快速开始（3 步）

### 1. 注册 Supabase 并创建数据库

1. 访问 [supabase.com](https://supabase.com) 注册账号
2. 创建一个新项目
3. 进入 **SQL Editor**，执行以下 SQL：

```sql
create table animes (
  id bigint generated by default as identity primary key,
  title text not null,
  total_episodes int,
  watched_episodes int default 0,
  status text default '想看',
  rating int,
  notes text,
  poster_url text,
  updated_at timestamp with time zone default now()
);
```

4. 进入 **Authentication > Policies**，为 `animes` 表添加策略：
   - 对 SELECT、INSERT、UPDATE、DELETE 都设置为 `true`（允许公开访问）

5. 在 **Settings > API** 中复制你的 **Project URL** 和 **anon public key**

### 2. 配置你的密钥

打开 `index.html`，找到第 443 行附近，替换：

```javascript
const SUPABASE_URL = 'https://xxxxxx.supabase.co';     // 改成你的 Project URL
const SUPABASE_KEY = 'eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9.....';  // 改成你的 anon key
```

### 3. 部署到公网（Cloudflare Pages）

1. 访问 [dash.cloudflare.com](https://dash.cloudflare.com) → **Workers & Pages**
2. 创建 Pages 项目，上传整个文件夹
3. 自动部署，获得 `xxx.pages.dev` 域名
4. Cloudflare 在国内有良好的 CDN 覆盖，图片代理和 API 代理自动生效

## 功能特性

| 功能 | 说明 |
|------|------|
| 📝 添加番剧 | 支持番名、总集数、已看集数、状态、评分、封面图、备注 |
| 📊 统计面板 | 实时显示总计/在看/想看/看完数量 |
| 🔍 搜索筛选 | 按名称搜索，按状态筛选 |
| 🎨 深色模式 | 跟随系统深色/浅色主题自动切换 |
| 📱 PWA | 可添加到手机主屏幕，像 App 一样使用 |
| ⌨️ 快捷键 | `Ctrl+N` 添加新番，`Esc` 关闭面板 |
| 💾 离线缓存 | 无网络时可查看上次同步的数据 |
| 🔄 实时同步 | 多设备打开同一网址，数据自动同步 |

## 部署后的效果

在任何设备的浏览器打开你的网址：
- 🖥️ 电脑：浏览器直接访问
- 📱 手机：浏览器访问，或添加到主屏幕
- 📟 平板：同样浏览器访问

所有设备共享同一份数据，修改实时同步。
