# 📺 补番目录

多端同步的追番进度管理工具 — 记录、追踪、发现你正在看的每一部番剧。

🔗 **在线地址**：[anime-txdlist.pages.dev](https://anime-txdlist.pages.dev)

## ✨ 功能特性

### 📝 番剧管理
- **添加 / 编辑 / 删除**番剧，支持标题、年份、总集数、封面图、备注
- **AniList / Bangumi 搜索**：输入中文/日文/英文/罗马音搜索番剧，自动填充评分、集数、年份
- **AniList 数据更新**：批量或单部从 AniList 同步最新评分、总集数、年份
- **评分彩色分级**：<5 绿 / 5-7 蓝 / 7-8 紫 / 8-9 金 / ≥9 彩虹渐变

### 📊 数据展示
- **实时统计卡片**：总计 / 在看 / 想看 / 看完 / 搁置 / 收藏，点击快速筛选
- **表头点击排序**：按名称 / 进度 / 状态 / 评分 / 年份排序，支持升降序
- **分页显示**：每页 12 条，支持跳页
- **搜索 + 筛选**：名称搜索 + 状态下拉筛选 + 收藏筛选
- **毛玻璃 UI**：深色/浅色主题跟随系统自动切换

### 🔄 交互功能
- **内联编辑**：点击集数直接修改，回车保存
- **状态快速切换**：点击状态标签弹出菜单选择
- **进度条可视化**：每部番剧显示观看进度百分比
- **拖拽排序**：拖拽番剧行调整默认排列顺序
- **更新后自动置顶**：任何信息变动后自动排到最上面
- **收藏星标**：一键收藏，独立筛选视图

### 📋 批量操作
- 勾选多部番剧，批量修改状态
- 全选 / 取消全选当前筛选结果
- 批量从 AniList 更新数据
- **JSON 导出 / 导入备份**：一键导出全部数据为 JSON，可随时导入恢复

### 📱 移动端
- **响应式布局**：手机端自动切换为卡片视图
- **移动端排序栏**：独立排序按钮组
- **PWA 支持**：可添加到主屏幕，离线缓存

### 🔐 账户系统
- Supabase Auth 登录 / 注册
- 个人资料编辑（用户名、头像）
- 多设备数据实时同步

## 🛠️ 技术栈

| 层 | 技术 |

| 前端 | Vanilla HTML/CSS/JS（零框架） |

## 🚀 自行部署

### 1. 创建 Supabase 项目

1. 注册 [Supabase](https://supabase.com)，创建新项目
2. 在 **SQL Editor** 执行建表语句：

```sql
CREATE TABLE animes (
  id BIGINT GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
  title TEXT NOT NULL,
  total_episodes INT,
  watched_episodes INT DEFAULT 0,
  status TEXT DEFAULT '想看',
  rating NUMERIC(3,1),
  year INT,
  notes TEXT,
  poster_url TEXT,
  anilist_id INT,
  sort_order INT DEFAULT 0,
  is_favorite BOOLEAN DEFAULT false,
  updated_at TIMESTAMPTZ DEFAULT now()
);
```

3. 启用 **Row Level Security** 并添加策略（或保持公开访问用于个人项目）
4. **（推荐）执行 `supabase/migrations/0001_user_isolation.sql`**：添加 `user_id` 列并创建按用户隔离的 RLS 策略，确保每个账号只能读写自己的数据
5. 在 **Authentication > Settings** 中启用 Email 登录
6. 复制 **Project URL** 和 **anon public key**

### 2. 配置项目

修改 `app.js` 顶部的密钥：

```javascript
const SUPABASE_URL = 'https://你的项目.supabase.co';
const SUPABASE_KEY = 'eyJ...你的anon key';
```

### 3. 部署到 Cloudflare Pages

```bash
npx wrangler pages deploy . --project-name <你的项目名> --branch main
```

## 📁 项目结构

```
animelist/
├── index.html          # 主页面
├── app.js              # 应用逻辑（主模块）
├── style.css           # 样式
├── supabase.min.js     # Supabase SDK（本地副本，更新时替换官方 CDN 最新版）
├── manifest.json       # PWA 配置
├── background.webp     # 背景图
├── sw.js               # Service Worker（离线缓存）
├── _redirects          # Cloudflare Pages 重定向
├── supabase/
│   └── migrations/
│       └── 0001_user_isolation.sql  # 用户数据隔离迁移（user_id + RLS）
└── functions/
    ├── api/
    │   ├── bangumi-proxy.js  # Bangumi 搜索代理（限流处理 + 边缘缓存）
    │   └── random-quote.js   # 随机动漫台词
    └── bgm-img/
        └── [[path]].js       # Bangumi 图片代理
```
